# MaverickD650 Labs — organisation defaults

This repository contains the shared community health files and documentation for
[MaverickD650 Labs](https://github.com/maverickd650-labs).

## What lives here

- `.github/` — default contribution, security, support and conduct guidance, plus
  issue and pull request templates.
- `profile/README.md` — the organisation's public GitHub profile.

GitHub uses supported community health files from this public `.github` repository
as defaults for repositories in the organisation when those repositories do not
provide their own versions. A repository's own file takes precedence, so projects
can keep the guidance and templates that need to be specific to their users or
technology.

## Important distinction

This repository does not automatically run GitHub Actions in other repositories.
Reusable workflows and shared actions must be called or referenced explicitly by
each project. Likewise, files such as `LICENSE`, Renovate configuration and
development instructions are not automatically inherited.

## Maintainers

MaverickD650 Labs is a small, independently maintained organisation. Projects may
have different contribution requirements, support expectations and release
processes; always check the target repository's README and local guidance first.
