# MaverickD650 Labs

Independent software projects, experiments and tooling by
[MaverickD650](https://github.com/MaverickD650).

The organisation provides a home for projects that benefit from shared
repositories, releases, automation and collaboration.

## Projects

- **[rss2discord](https://github.com/maverickd650-labs/rss2discord)** — a
  Kubernetes operator that delivers RSS and Atom feed updates to Discord.
- **[cluster-docs](https://github.com/maverickd650-labs/cluster-docs)** — a
  Zensical static site supporting the cluster with technical documentation.

More projects will appear here as they become ready to share.

## Focus areas

- Kubernetes and cloud-native software
- Go, automation and developer tooling
- Open-source infrastructure and supply-chain security

## Contributing

Issues and pull requests are welcome where a project is open to contributions.
Please read the relevant repository's README and contribution guidance before
getting started. The organisation's shared
[community standards](https://github.com/maverickd650-labs/.github) provide
defaults; individual projects may add their own requirements.

Projects are maintained independently and in spare time, so response times and
support availability can vary. Thank you for taking an interest.
